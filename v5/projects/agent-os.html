Agent OS — AI Agent 거버넌스 플랫폼

조직 내 흩어진 AI Agent들을 한 곳에서 등록·추적·통제하는 거버넌스 플랫폼 — Go + Next.js 모노레포.

역할
Go 백엔드 + Next.js 콘솔 개발
기간
2026.06 — 현재 · SK Telecom
규모
BDD 20 스펙 · agent-os-skills 49 커밋
스택
Go(Huma) · Next.js · Langfuse · Speckit

Go 기반 control-plane과 Next.js 콘솔로 구성된 모노레포에서 백엔드와 프론트엔드를 오가며 개발합니다. spec→plan→tasks→구현으로 이어지는 Speckit 스펙 주도 개발을 실천하며, 팀 생산성을 위한 자동화 스킬도 직접 만듭니다.

What I Built

  • Observability Pod — Go control-planeLangfuse/Pathfinder trace 조회 연동: cursor 페이징, 오류 계약 매핑, 지수 백오프 재시도. BDD tests-first로 20개 스펙을 먼저 작성.
  • Model Evaluation 콘솔 — Next.js화면 개발 및 리팩토링, flaky test 근본 해결.
  • Speckit 스펙 주도 개발spec→plan→tasks→구현 흐름 실천, GitLab 이슈/Epic 양방향 연결 자동화.
  • agent-os-skills — 팀 생산성 자동화daily-briefing(Slack Block Kit 발송), spec-tracker(스펙 번호 충돌 자동 재번호) 등 자동화 스킬 개발 · 49 커밋.

Outcome

Go 백엔드부터 Next.js 콘솔, 팀 자동화 스킬까지 — 플랫폼 개발과 개발 문화(스펙 주도·BDD tests-first)를 함께 만들어가는 중.

Pantech Android 디바이스에 preload되는 Music Player 앱을 개발했습니다. Media Provider Framework 분석부터 ID3/FLAC 파일 스펙 레벨의 Tag Editor Java Library 자체 개발까지 — 국내 전모델과 일본/베트남/대만 preload, Android 2.2~5.0 OS 업그레이드를 대응했습니다.

What I Built

  • Music Player — preload 앱Android Media Provider Framework 분석, Music DB/Albumart cache 구조, AppWidget 2종 + U+Box 위젯.
  • 온라인 연동·글로벌 preloadMelon/OllehMusic/YouTube 온라인 서비스 연동, 국내 전모델 + 일본/베트남/대만 preload, Android 2.2~5.0 OS 업그레이드 대응.
  • Audio Effect 앱사용자 설정 Equalizer, 장르별 Auto Preset, QSound/NXP 3rd party 통합.
  • Tag Editor Java Library 자체 개발MP3(ID3)/FLAC(Vorbis) spec 분석, TEXT/LYRICS/ALBUMART read/write, charset encoding 자동 분석.

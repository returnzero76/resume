Audio Effect Android

음원 재생 관련 Audio Effect를 제공하는 앱을 개발했습니다.

역할
전임연구원 · Android 앱 개발
기간
2012.04 — 2015.05 · Pantech
통합
QSound · NXP · Android Native — 하나의 apk
스택
Java · Equalizer · Effect Tuning

Effect 종류별 사용자 UI와 사용자 설정 가능한 Equalizer, 재생 장르 기반 Auto Preset 기능을 개발했습니다. QSound/NXP/Android Native 3rd party 라이브러리를 하나의 apk로 통합했고, 타사 디바이스와 모든 뮤직 플레이어 앱에서 동작하도록 개발했습니다.

What I Built

  • Effect UI · EqualizerEffect 종류별 사용자 UI 개발, 사용자 설정 가능한 Equalizer, 재생 장르 기반 Auto Preset 기능 개발.
  • 3rd party 라이브러리 통합QSound/NXP/Android Native 통합 — 하나의 apk로 모두 지원, Effect tuning.
  • 호환성 확장타사 디바이스·모든 뮤직 플레이어 앱에서 동작하도록 개발.

Outcome

서로 다른 3rd party Effect 라이브러리를 하나의 apk로 통합하고 타사 디바이스까지 지원 — 디바이스에 종속되지 않는 Audio Effect 앱을 만들었습니다.

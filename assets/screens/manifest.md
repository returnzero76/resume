# 프로젝트 스크린샷 매니페스트

강지환 이력서 페이지에서 사용하는 프로젝트 스크린샷 목록.

- `assets/screens/NAME.jpg` — 썸네일(긴 변 ≤900px, JPEG q82). 페이지 그리드에 노출.
- `assets/screens/full/NAME.jpg` — **라이트박스용 고해상도 원본**(긴 변 ≤1600px, JPEG q85). 파일명은 썸네일과 동일하며, 모든 썸네일에 1:1로 대응하는 full/ 파일이 존재.
- 원본이 목표 해상도보다 작으면 업스케일하지 않고 원본 해상도를 유지.
- 포맷: `파일명 | 프로젝트 | 화면 설명 | WxH | 용량`

## 개인정보로 제외한 원본

- 에이닷: 오늘의 운세 대화 화면(실명 노출), 스퀴즈런 채팅(타 사용자 닉네임·응원 메시지), 튜터 홈 구버전(실명 인사말)
- Tmon: 마이티몬(실명 + 티몬캐시/적립금 잔액 205,681원)
- NUGU Mobile: 마이 화면 상단 계정 영역(`jihwan.kang@sk.com`) — 해당 영역을 크롭한 하단부만 사용, NUGU call 연락처 목록(타인 실명 포함) 전체 제외
- Tmap Taxi: 승객 호출 3종 고해상도 원본(출발지에 자택 아파트 동 주소 노출) — 개인정보 없는 화면으로 전면 교체, GNB/설정(실명·passengerId·사번 이메일), 앱결제 수단(카드 뒷자리 7081), Fastlane Slack 캡처(타인 이메일)
- Winvention: Change profile(계정 이메일), 마이페이지(계정 ID·가입일·T-Cash)

## 아직 이미지가 없는 프로젝트

- **Agent OS** — 사내 콘솔로 캡처 불가(아키텍처 SVG만 보유)
- **adot-react-native (공용 RN 워크스페이스)** — 별도 앱이 아니라 submodule 코드베이스, 화면 없음
- **Tmap x Adot 음성비서 마이그레이션 샘플 앱** — 파트너사 참조용 내부 샘플 앱이라 캡처 없음(`tmap-store-*`는 Tmap 앱 스토어 이미지로 대체)
- **Blu-ray Player (LG전자 인턴)** — 디바이스 SW라 스크린샷 없음
